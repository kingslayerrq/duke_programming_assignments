# Assignment 000

This problem is for you to practice submitting assignments.

### Prerequisites
The following instructions assume you've already forked the assignment project in [gitlab](https://gitlab.oit.duke.edu).

If not, **STOP**

Follow these instructions and come back:
[Setup](https://gitlab.oit.duke.edu/gddi-590-f2025/dev-guides)

## Instructions
- Create a file named `my-net-id.txt` inside the `000_submit` directory
- Open the file you created
- Enter your alpha-numeric netID on the first line
- Save and close the file
- Commit your changes
- Push your changes to Gitlab
- In Gitlab, submit a merge request
