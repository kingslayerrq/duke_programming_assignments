# Assignment 013

It's been a tough day at `SuperAmazing Game Company Inc.`

Your game is almost ready to ship to an overseas QA group, but the build system crashed!

There's a lot of pressure from stakeholders to meet deadlines, so the PM is coming around having the devs chip in with some preliminary testing.

## Instructions
 
1. Create a file called `answer.txt`
    > NOTE: 
    >
    >   The file name is singular, not plural

2. Read the code in `test.c`

3. As you read the code, type the output into your file `answer.txt`
    > NOTE:
    >
    >   Yes, we expect you to reason through the code and type out
    >   the expected output.
    >
    >   You will see similar exercises on the midterm.

4. Create a `Makefile` to compile `test.c` into a program called `test`
    > NOTE:
    >
    >   Assignment 010_rectangle has a Makefile you can use a reference
    >   
    >   When your Makefile is ready, you can use it to build your program
    >   by typing the following into the terminal:
    >
    >   make
    
5. Run `test` and use its output to check your work.

6. Submit the assignment as normal.
